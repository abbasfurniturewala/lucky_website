    Connect private reporting access

    Enable the Data API and authorize a Viewer-only account. Keep credentials outside Git and the public website.

    Configure the website tracking tag

    Add the G-… Measurement ID, review privacy wording, and turn OFF all Enhanced measurement in the Web stream. This avoids duplicate views and automatic link/query collection.
